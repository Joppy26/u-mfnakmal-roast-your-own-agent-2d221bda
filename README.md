Entry for the [Roast Your Own Agent bounty](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda) on make.fun.

## The roast

> My agent turns a five-minute task into a three-act epic: research, refactor, and a README nobody asked for.

## How it works

`main.ts` writes the roast line to `/output/entry.txt`. The line is a fixed
constant, so every run produces byte-identical output.

Run it with:

```sh
node main.ts
```
